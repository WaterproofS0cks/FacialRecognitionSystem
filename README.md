AI FACE RECOGNITION SYSTEM

 Python face recognition system using NumPy, pickle, and Firebase. It identifies users from .png files in a folder, denying entry to unrecognized faces. The project showcases machine learning, data handling, and security authentication.


### GUIDE

```
{
  "type": "",
  "project_id": "",
  "private_key_id": "",

  "auth_provider_x509_cert_url": "",
  "client_x509_cert_url": "",

}
```
